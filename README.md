# PhysLab 🔬

**Физика, которую можно увидеть.**

🌐 **[Открыть сайт → nikitagut.github.io/physlab](https://nikitagut.github.io/physlab)**

Интерактивный сайт с физическими моделями для школьников: меняй параметры, запускай эксперименты и наблюдай результат. Без регистрации, без установки — открыл ссылку в браузере и исследуешь.

## ✨ Что внутри

На главной странице — каталог моделей с поиском и фильтрацией по категориям. Каждая модель — отдельная страница с визуализацией, ползунками параметров и живыми показаниями физических величин.

Уже готово:
- 🚗 **Равномерное движение** — скорость, путь, время
- 🏎️ **Второй закон Ньютона** — сила, масса, ускорение + график `v(t)`

В планах:
- 🪂 Свободное падение
- ⚽ Бросок под углом
- 🔌 Закон Ома
- 🌊 Гармонические колебания

## 🛠 Технологии

- **HTML5** — разметка страниц
- **CSS3** — тёмная тема, адаптивная вёрстка, CSS-переменные
- **JavaScript** — физика, анимация, управление интерфейсом
- **Canvas API** — визуализация движения тел
- **Chart.js** — графики зависимостей

Никаких фреймворков и сборщиков — чистые веб-технологии.

## 📁 Структура проекта

```

physlab/
├── index.html              # Главная — каталог моделей
├── css/
│   └── style.css           # Общие стили
├── js/
│   ├── main.js             # Поиск и фильтры на главной
│   └── models-data.js      # Описание всех моделей
├── models/
│   ├── uniform-motion.html # Равномерное движение
│   └── newton-second.html  # Второй закон Ньютона
└── README.md

```

🎯 Принципы

· Простота. Одна модель — одна HTML-страница. Легко читать, легко поддерживать, легко добавлять новое.
· Реальная физика. Расчёты идут по настоящим формулам, интегрирование по времени, а не «пиксели за кадр».
· Наглядность. Каждое изменение параметра сразу видно на экране и на графике.
· Работает на телефоне. Вёрстка адаптивная — открывается и на школьном ПК, и на смартфоне.

👩‍🎓 Учебный проект

Сделан как школьное задание по информатике. Цель — показать, что физику можно изучать не по скучным формулам, а играя с параметрами и сразу видя результат.
